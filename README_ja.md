# pgextwin — Windows向けPostgreSQL拡張機能

[English](README.md) | 日本語

pgextwinはPostgreSQL拡張機能の**非公式Windows x64バイナリ**を配布するコミュニティプロジェクトです。PostgreSQL、EDB、各拡張機能の開発元による公式配布ではありません。

## 拡張機能を探す・ダウンロードする

[pgextwinの拡張機能カタログ](https://pgextwin.github.io/website/ja/)では、プロジェクトが扱う**17種類の拡張機能**、公開済みバージョン、対応PostgreSQL、ダウンロード先を確認できます。対象拡張機能に含まれていても、新しい上流バージョンが公開済みとは限りません。

各拡張機能の[GitHubリポジトリ](https://github.com/orgs/pgextwin/repositories)にある**Releases**ページでも、公開済みパッケージとリリースノートを確認できます。

## 対応環境とインストール

- 対応環境は**Windows x64**です。PostgreSQL **14〜18**向けのパッケージが公開されていますが、対応範囲は拡張機能とReleaseによって異なります。
- PostgreSQL 14のコミュニティサポートは**2026年11月12日**に終了します。サポート終了後も過去の配布ファイルは残る場合があります。
- **利用中のPostgreSQLメジャーバージョンに一致するZIP**を選んでください。異なるメジャーバージョン向けのファイルを混在させないでください。
- ファイルの配置と設定は各拡張機能のREADMEと上流ドキュメントに従ってください。事前ロードの設定と再起動が必要なものや、実行ファイルが付属するものなど、手順は拡張機能ごとに異なります。
- 本番導入前にバックアップを取り、検証環境で動作を確認してください。

## ダウンロードしたファイルを確認する

各Releaseには、ファイルの整合性を照合できる**SHA256SUMS.txt**が付属します。Releaseによっては、SPDX形式の構成部品表（SBOM）、脆弱性レポート、署名付き証明も提供しています。実際に付属するファイルはReleasesページで確認してください。これらの資料は、脆弱性が存在しないことを保証するものではありません。

## 上流プロジェクトとライセンス

拡張機能のSQL、設定方法、制限事項は各上流プロジェクトの説明を参照してください。ライセンスは各パッケージに付属するファイルで確認できます。pgextwinは上流プロジェクトからの承認・推奨を示すものではありません。
